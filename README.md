# Site do Cubo Estúdio

Página inicial e política de privacidade públicas, exigidas pelo Google para publicar o app OAuth da
Fábrica de Vídeos (projeto `fabrica-videos`). Publicado pelo GitHub Pages em
https://jeffersonperosso.github.io/.

- `index.html`: página inicial do app.
- `privacidade.html`: política de privacidade (YouTube API Services).
